Use this skill for ANY task that involves a user interface written in Rust, desktop or web: windows, views, widgets, forms, layout, theming, accessibility, keyboard focus, loading and error states. Invoke it before writing, reviewing or changing UI code, even for small edits and even when no framework is named (a Rust desktop app, a native Linux app in Rust, a Rust WebAssembly frontend, a GUI for a Rust tool). Covers libcosmic, GPUI, Iced, Topcoat, Leptos, Yew, Tauri, Dioxus, egui or eframe, Slint, GTK4 or gtk-rs, libadwaita and Relm4. Not for backend services, APIs, command-line tools or terminal UIs (axum, clap, ratatui), game engines, or interfaces in other languages (React, Flutter, Qt in C++).
