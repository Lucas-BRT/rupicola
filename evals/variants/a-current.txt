Guides planning, building, reviewing and improving user interfaces written in Rust for desktop and web, including windows, views, widgets, forms, layout, theming, accessibility, keyboard focus and async loading states. Use whenever a task touches a Rust UI framework (libcosmic, GPUI, Iced, Topcoat, Leptos, Yew, Tauri, Dioxus, egui or eframe, Slint, GTK4 or gtk-rs, libadwaita, Relm4), even when the framework is not named, for example a Rust desktop app, a native Linux app in Rust, a Rust WebAssembly frontend or a GUI for a Rust tool. Not for backend services, APIs, command-line tools or terminal UIs (axum, clap, ratatui), game engines, or interfaces in other languages (React, Flutter, Qt in C++).
