# Project context

Use `.ferris-atelier/context.md` for explicit project-context requests. Record product tasks, packages, resolved dependency versions or uncertainty, features, renderers, OS targets, brand decisions, accepted exceptions and verification evidence. Distinguish user decisions from inferred assumptions and date volatile facts.

Read existing context when it participates in the current task. Do not create context files during ordinary small edits unless requested. Preserve existing user records; this skill does not automatically migrate or delete other tools' state directories.

Optional `visits: enabled` allows review records under `.ferris-atelier/visits/`. Otherwise return the report without automatically persisting it. Store reusable decisions rather than copied manuals, transcripts or tool dumps.
