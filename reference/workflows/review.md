# Review an interface

Inspect the named tasks and relevant package, then the running product where available. Select framework, environment and UX guidance relevant to observed behavior. Confirm static scan candidates in context. Prioritize task failure, false states, data loss and accessibility before aesthetic preferences.

Check the screen against the [tactics library](../tactics/index.md) and report a missing tactic as a defect only when it causes a task failure, a false state or an accessibility barrier; otherwise list it as an opportunity. Report missing motion as a defect only when a state change goes unnoticed or disorients the user; otherwise list it as an opportunity with a tactic from [motion library](../motion/index.md).

When a capture is possible, capture the affected states and review the images and write findings in the format of [visual critique](../critique.md) with evidence labels; mark interaction-dependent judgments as needing an interactive check.

Return findings using reference/reports.md. Report unavailable runtime, input and profiling checks explicitly. Stop after diagnosis; do not edit application code. Persist a visit only when project context enables it or the user requests a record.
