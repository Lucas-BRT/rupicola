# webview

Webview engines are pinned by the OS and differ per target; check [modern web features](../web/modern-css.md) against each engine before using a newly available feature.

Compose desktop and web guidance. Identify the engine per OS, restrict IPC capabilities and remote content, and handle external navigation explicitly.

Inspect the current renderer and supported versions before prescribing APIs. Build success alone does not establish usable behavior.
