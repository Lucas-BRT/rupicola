# web

Preserve semantic controls, URLs/history, keyboard focus, zoom and forms. Identify CSR/SSR/hydration and browser policy. Verify initial rendering and client interaction independently.

For layout, theme or styling defects, use [CSS diagnosis](../web/css-diagnosis.md) to trace the rule responsible and check the fix against real content and container sizes.

For newer platform features (cross-document view transitions, scroll-driven animations, anchor positioning, customizable select and others), their support status and when not to use them, read [modern web features](../web/modern-css.md).

Inspect the current renderer and supported versions before prescribing APIs. Build success alone does not establish usable behavior.
