# Accurate comparison

Read when the task affects accurate comparison.

## Recipe

Problem: the task may become hard to understand or operate when this concern is ignored.

Technique: Use explicit units, truthful scales, stable sorting and appropriate tables/charts. Represent missing data and uncertainty honestly.

When to avoid or adapt: A large stat card is not necessarily useful; a chart can conceal exact comparisons a table exposes.

Verification: Compare displayed values to source data, test filters and sorting and inspect non-color alternatives.

## Adaptation and evidence

Use the actual framework and renderer APIs. DOM techniques apply to DOM renderers; desktop widgets require their own semantic/input mechanisms. Preserve applicable OS conventions and project identity. These are contextual heuristics unless the linked standard defines an applicable requirement.
