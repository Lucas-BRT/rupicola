# Hierarchy and adaptable density

Read when the task affects hierarchy and adaptable density.

## Recipe

Problem: the task may become hard to understand or operate when this concern is ignored.

Technique: Give task content priority through size, space and alignment. Reuse project scales and allow content-driven resizing.

When to avoid or adapt: A dense editor may need compact rows; excessive whitespace can slow work.

Verification: Resize and enlarge text; confirm task controls remain visible and reachable.

## Adaptation and evidence

Use the actual framework and renderer APIs. DOM techniques apply to DOM renderers; desktop widgets require their own semantic/input mechanisms. Preserve applicable OS conventions and project identity. These are contextual heuristics unless the linked standard defines an applicable requirement.
