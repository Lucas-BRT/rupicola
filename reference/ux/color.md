# Meaning and contrast

Read when the task affects meaning and contrast.

## Recipe

Problem: the task may become hard to understand or operate when this concern is ignored.

Technique: Use semantic color roles and redundant text/shape signals for selected, error and warning states.

When to avoid or adapt: Brand colors can remain; a hue alone does not establish a usability defect.

Verification: Check actual foreground/background contrast in supported themes and identify states without color.

## Adaptation and evidence

Use the actual framework and renderer APIs. DOM techniques apply to DOM renderers; desktop widgets require their own semantic/input mechanisms. Preserve applicable OS conventions and project identity. These are contextual heuristics unless the linked standard defines an applicable requirement.

[Source](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html). Check the applicable version and scope before making a compliance claim.
